# Лабораторная работа №2. Вёрстка UI и навигация между экранами

Студент: Ретунский Савелий

## Описание проекта
Приложение разработано в рамках лабораторной работы №2 по курсу мобильной разработки для ОС Android.

Включает выполнение двух заданий:
1. **Вёрстка и работа с UI-элементами (ConstraintLayout)**:
   - Форма регистрации: ввод имени (`EditText`), возраста (`EditText` с числовым вводом), чекбокс согласия с правилами (`CheckBox`) и кнопка подтверждения (`Button`).
   - Проверка введённых данных: непустые поля, возраст в диапазоне от 0 до 150 лет, проверка согласия.
   - Вывод обратной связи пользователю через всплывающие сообщения (`Toast`).

2. **Навигация между экранами и передача данных (Intent)**:
   - Главный экран (`MainActivity`) с полем ввода и кнопкой перехода.
   - Передача строковых данных между экранами через `Intent.putExtra()`.
   - Детальный экран (`DetailActivity`) на базе `LinearLayout` с отображением переданного текста и кнопкой возврата (`finish()`).

## Сборка и запуск
- Минимальная версия Android SDK: API 24 (Android 7.0)
- Целевая версия Android SDK: API 37
- Язык разработки: Kotlin
- Готовый установочный файл приложения: `app-debug.apk` в корне репозитория.
